# Security Policy

## Scope & Research Nature

The Quantum Security Toolkit (QST) is an educational, scientific simulation, and research toolkit designed for studying Quantum Key Distribution (QKD) concepts, BB84 protocol dynamics, Cascade error correction, and 2-universal privacy amplification.

It is **not** a hardware-based cryptosystem, physical cryptographic appliance, or production communication security deployment. It operates as software running on classical computing environments.

## Supported Versions

Only the latest stable release of the Quantum Security Toolkit (QST) is supported for security updates:

| Version | Supported |
| ------- | --------- |
| v1.0.x  | Yes       |
| < v1.0  | No        |

## Reporting a Vulnerability

We take the software security of QST seriously (including input validation, path traversal defense, resource exhaustion prevention, and dependency safety).

If you discover a potential vulnerability in QST:

1. **Do not open a public issue.**
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/shlok926/Project-Q-30-Days-Challenge/security/advisories) or by emailing: `shlokthorat29075@gmail.com`
3. Please include:
   - Detailed description of the vulnerability.
   - Steps or proof-of-concept to reproduce the issue.
   - Potential impact on simulation stability or host system.
4. We will acknowledge receipt within 48 hours and coordinate a timely fix and advisory.
