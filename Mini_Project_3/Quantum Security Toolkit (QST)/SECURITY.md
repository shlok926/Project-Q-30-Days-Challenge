# Security Policy

## Supported Versions

Only the latest stable release of the Quantum Security Toolkit (QST) is supported for security updates:

| Version | Supported |
| ------- | --------- |
| v1.0.x  | Yes       |
| < v1.0  | No        |

## Reporting a Vulnerability

We take the security of QST seriously. If you find a security vulnerability, please report it via the following steps:

1. **Do not open a public issue.**
2. Send a detailed report to `security@qst-project.org` containing:
   - Steps to reproduce the issue.
   - A proof-of-concept script.
   - The potential impact.
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you to patch the issue.
4. We aim to release a patch and publish a public advisory within 30 days of receiving the report.
