# QST Future Roadmap

This document outlines the v1.0.0 milestones achieved and details our plans for subsequent development versions.

## Completed Milestones (v1.0.0 Stable)
- **Phase 1-11 (Foundations & CLI):** BB84 state preps, key sifting, eavesdropping simulation, visualizer backend, CSV/JSON exports, sweep parameters engine, and test suites.
- **Phase 12 (IBM Runtime):** Integration with IBM QPU backends, remote simulators, and Aer fallback mechanisms.
- **Phase 13A (Cascade):** Recursive Cascade error correction reconciler and block shuffles.
- **Phase 13B (Privacy Amplification):** 2-universal Toeplitz hashing matrices generators, Min-Entropy calculations, and trace distance bounds estimators.
- **Phase 13C (Metrics & Summary):** E2E summary builders, rate calculators, and configurable security classification parameters.
- **Phase 14 (Release Engineering):** Version freezing, package builds validations, supply-chain checks, and comprehensive documentation guides.

## Future Roadmap (v1.1+)
- **Alternative QKD Protocols:** Implement E91 entanglement-based protocol and B92 simplified states protocol.
- **Decoy-State BB84:** Introduce decoy-state configurations to mitigate photon-number-splitting (PNS) attacks.
- **Finite Key Analysis:** Incorporate corrections for finite-key regimes in security parameter bounds.
- **LDPC Error Correction:** Add low-density parity-check code reconciliation as alternative to Cascade.
- **Multi-Node Simulation:** Support multi-node network simulation modeling multiple hops or quantum repeaters.
- **Hardware Benchmarks:** Automated physical quantum computer benchmarking suite tracking gate error drift.
